# Hijab by Eliza — Natural / V1

Это первый браузерный прототип виртуального хиджаба.

Что внутри:
- `index.html` — камера + MediaPipe Face Landmarker + позиционирование хиджаба
- `hijab_ar_asset_v1.png` — подготовленный AR-ассет

Важно:
1. Это V1-прототип. Хиджаб пока является плоским 2D-слоем.
2. При сильном повороте головы края могут выглядеть неестественно.
3. Камера браузера обычно требует HTTPS (или localhost).
4. Для публикации удобно использовать GitHub Pages.

Как запустить:
- Самый простой способ: загрузить все файлы в GitHub repository и включить GitHub Pages.
- Открой опубликованный HTTPS-адрес на iPhone в Safari.
- Нажми «Запустить камеру» и разреши доступ к камере.

Если хиджаб слишком большой/маленький:
в `index.html` найди:
`const drawW = faceWidth * 3.05;`
и измени `3.05`.
Например:
`2.8` — меньше,
`3.3` — больше.

Если хиджаб слишком высоко/низко:
в `index.html` найди:
`const drawY = topY - faceHeight * 0.70;`
и измени `0.70`.
